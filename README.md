
# AI Internship – CODSOFT

This repository contains the work completed during my **Artificial Intelligence Internship at CODSOFT**, where I worked on three hands-on tasks focused on applying AI and Machine Learning concepts to real-world problems.

##  Internship Tasks

### Task 1 – Chatbot

Developed an AI-based chatbot capable of interacting with users and providing relevant responses using Natural Language Processing (NLP) concepts.

### Task 2 – Recommendation System

Built a recommendation system that analyzes user/item information and generates personalized recommendations using Machine Learning techniques.

### Task 3 – Image Captioning

Developed an image captioning system that combines **Computer Vision and Natural Language Processing** to generate meaningful textual descriptions for images.
